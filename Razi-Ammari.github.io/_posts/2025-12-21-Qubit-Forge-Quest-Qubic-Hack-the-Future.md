## Overview
**Qubit-Forge-Quest (QFQ)** is a **decentralized compute marketplace** for the **Qubic** ecosystem, built for the **Nostromo Launchpad Track** of the **Qubic "Hack the Future" Hackathon**. It shows how computation can become a **transparent, scalable and fair on-chain economy**.

- 🌐 Live demo: [qubit-forge-quest-front.vercel.app](https://qubit-forge-quest-front.vercel.app/)
- 📁 Repositories: [front-end](https://github.com/Razi-Ammari/qubit-forge-quest-front) · [back-end](https://github.com/Razi-Ammari/qubit-forge-quest-Backend)

## How it works
- **Creators** submit compute jobs and pay in **Compute Credits (CC)**.
- **Investors** stake **QX tokens** to earn CC yield.
- A background **execution engine** processes tasks in parallel with queue management, retries and real-time metrics.
- **Admins** keep the ecosystem balanced and approve role upgrades.

## Features
- **JWT** and **Google OAuth** authentication with role-based access (User → Creator / Investor → Admin).
- Role-specific dashboards (Creator, Investor, Admin).
- Staking & reward tracking, task history (Queued / Running / Completed / Failed).
- Ecosystem analytics — a full economic simulation of a tokenized compute network.

## Tech Stack
`React + TypeScript (Vite)` · `Tailwind / shadcn-ui` · `Node.js / Express` · `MongoDB` · `JWT` · `Google OAuth` · `Vercel` · `Render`
