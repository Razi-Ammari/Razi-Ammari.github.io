## Key Takeaways
- **Cluster setup & hardening**: CIS benchmarks, securing the API server, kubelet and etcd.
- **RBAC & service accounts**: least-privilege access in multi-tenant clusters.
- **Network Policies**: restricting pod-to-pod traffic and isolating namespaces.
- **Supply-chain security**: image scanning, signed images and admission control.
- **Runtime security**: syscall monitoring, AppArmor / seccomp profiles and audit logging.
- **Linux**: file system, permissions, processes, package management and shell scripting.

This is the core of my **cloud security** profile: securing workloads, not just deploying them.
