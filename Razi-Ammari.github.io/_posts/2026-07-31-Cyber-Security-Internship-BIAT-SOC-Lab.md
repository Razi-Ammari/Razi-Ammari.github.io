## Overview
From **June to July 2026** I worked as a **Cyber Security Intern at BIAT** (Banque Internationale Arabe de Tunisie), contributing to cybersecurity and **SOC operations** within an enterprise banking IT environment.

## SOC Detection & Incident-Response Lab
I built an **isolated SOC lab** covering the full chain: attack simulation → telemetry collection → detection → investigation → incident reporting.

**Stack:** Splunk · Sysmon · Windows · Kali Linux · Splunk Universal Forwarder

**Scenarios investigated** (controlled):
- **RDP brute-force** attempts.
- **Phishing-style execution** on an endpoint.
- **Suspicious PowerShell** activity.

**Techniques applied:**
- SIEM-based **alert triage** and event correlation.
- **MITRE ATT&CK** mapping, **IOC / IOA** analysis.
- Windows **Event ID** investigation and **process-tree** analysis.
- **Timeline reconstruction**, severity assessment and **L2 escalation**.

## Enterprise Security Exposure
- Security architecture: **SIEM, SOAR, EDR, XDR, NDR, WAF**, firewalls, proxy / reverse proxy, DNS security.
- Network: **VLAN segmentation** and **MPLS**.
- Platforms: **Windows Server, Active Directory, Red Hat OpenShift**, microservices and enterprise network monitoring.

## Training
Completed TryHackMe **Pre Security**, **Cyber Security 101** and **SOC Level 1** as part of the internship program.
