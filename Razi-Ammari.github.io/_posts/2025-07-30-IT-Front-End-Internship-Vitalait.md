## Overview
In **July 2025** I joined **Vitalait Tunisie** as an **IT & Front-End Development Intern** (hybrid), one of Tunisia's leading dairy companies.

## What I built
A professional static web application for **IT asset management**, built with **HTML, CSS and Bootstrap**:
- **Authentication** pages.
- A **dashboard** giving an overview of the IT park.
- **Asset tracking** pages (equipment, assignment, status).
- **User roles** management screens.

The result is a responsive, user-friendly interface that improves usability and gives a solid base for a future back-end.

## Skills
Responsive web design · prototyping · UI/UX · HTML5 · CSS3 · Bootstrap
