# Razi Ammari — Portfolio

Personal portfolio of **Razi Ammari**, Cloud & Cybersecurity engineering student at ESPRIT: certifications, achievements, hackathons, projects and experience.

🌐 **Live:** https://razi-ammari.github.io

Built with [Jekyll](https://jekyllrb.com) and the [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) theme, deployed by GitHub Actions to GitHub Pages.

## Add a new certification / achievement
1. Create `_posts/YYYY-MM-DD-Title.md` with front matter (`layout: post`, `title`, `date`, `categories`, `tags`, `image`).
2. Put the image in `images/certif/` (or `images/projects/`, `images/competitions/`).
3. Add a row to the certification wall in `_tabs/about.md`.
4. Commit & push — the site redeploys automatically.

## Run locally
```bash
bundle install
bundle exec jekyll serve
```
